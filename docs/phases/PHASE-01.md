# Phase 1 — Product Foundation

Status: `HISTORICAL_PLAN`
Migration: `PARTIALLY_MIGRATED`
Build eligibility: `NOT_READY_FOR_BUILD`

## Purpose

Establish the foundational Aevum product direction: what the system is, who it is for, what problem space it addresses, and which principles should constrain later design.

## Historical scope

Phase 1 established the initial personal-life-system direction that later planning refined into Aevum.

The durable outcomes now represented elsewhere in the repository include:

- Aevum as a long-term personal organizational intelligence system;
- support for meaningful personal context, goals, decisions, activities, reflection, and AI-assisted understanding;
- a requirement that the product become more useful as context accumulates over time.

## Dependencies

None. This is the foundational historical planning phase.

## Superseding refinement

Phase 1 must be interpreted together with **Phase 1.2**, which corrected developer-centric aspects of the original product model.

No future BUILD may implement an obsolete Phase 1 interpretation that conflicts with the approved Phase 1.2 direction.

## Deliverables preserved in Baseline v1

- project vision and intended audience;
- core product principles;
- high-level product concepts;
- initial implementation-source context for the first future BUILD slice.

## Requirements for BUILD conversion

Before a Phase 1-derived implementation can become `READY_FOR_BUILD`, SPEC must define:

- the concrete first user-visible software milestone;
- exact frontend/backend deliverables;
- repository/project structure;
- minimum persistence model;
- required APIs/interfaces;
- environment/configuration requirements;
- security baseline;
- testing and verification requirements;
- acceptance criteria;
- Definition of Done;
- explicit non-goals and deferred features.

## Acceptance / Definition of Done

Historical Phase 1 is a planning phase and is **not** BUILD-ready in this baseline. Its future implementation slice must receive new testable acceptance criteria through PSB SPEC.
